# 직원에게 넘기기 전 대표님이 하실 일

## 1. 직원 계정 만들기

`계정 관리` 메뉴 → **직원 계정 추가**

- 아이디: 영문 소문자·숫자 (예: `younghee`)
- 이름: 실명
- 권한: **직원**을 고르세요

만들면 **임시 비밀번호가 화면에 한 번만** 나옵니다. 그 화면을 벗어나면 다시 못 봅니다.
(잃어버려도 `비밀번호 초기화`를 누르면 새로 나옵니다.)

직원은 첫 로그인에서 비밀번호를 반드시 바꿔야 들어옵니다.

## 2. 권한이 나뉘는 지점

| | 직원 | 관리자 |
|---|---|---|
| 대시보드 · 주문·현장 · 사진 검수 · 리워드 · 발송 로그 · 엑셀 업로드 | ✅ | ✅ |
| **설정** (발송 허용 번호, 알림톡 채널, 리워드 문구) | ❌ | ✅ |
| **계정 관리** | ❌ | ✅ |

**설정을 잠근 이유:** 설정의 `발송 허용 번호`를 비우는 순간 전 고객에게 실제 알림톡이 나가기 시작합니다. 직원이 실수로 누를 수 있는 곳에 두면 안 됩니다.

## 3. 계정 하나를 여럿이 쓰지 마세요

사람마다 계정을 주면:
- 누가 어떤 사진을 승인했고 리워드를 얼마로 정했는지 기록에 남습니다
- 퇴사하면 그 계정만 **사용 중지**하면 됩니다. 중지하면 그 사람이 로그인해 있던 세션까지 즉시 끊깁니다
- 다른 사람 비밀번호를 바꿀 필요가 없습니다

## 4. 아직 대표님만 하셔야 하는 일

- **실제 발송 시작** — 설정의 `발송 허용 번호`를 비우는 것. 테스트가 끝나기 전에는 비우지 마세요
- 알림톡 문구 변경, 리워드 금액 기준 결정
- 솔라피 잔액 관리
