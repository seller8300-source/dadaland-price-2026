# 카카오 알림톡 템플릿 신청서 (스톤킴 시공사진 수집)

카카오 비즈니스 채널 > 알림톡 템플릿 등록에 그대로 입력할 내용이다.
검수는 영업일 기준 2~3일 걸리므로 **발송 시작 예정일 최소 1주 전에 신청**한다.

## 0. 사전 준비

| 항목 | 내용 |
|---|---|
| 카카오톡 채널 | 스톤킴 공식 채널 (비즈니스 인증 완료 필요) |
| 발신 프로필 키(pfId) | 채널 연동 후 발급 → `STONEKIM_KAKAO_PFID` |
| 발신번호 | 사전 등록한 회사 번호 → `STONEKIM_MSG_SENDER` (대체발송용) |
| 업로드 도메인 | 예: `https://photo.stonekim.co.kr` (버튼 URL 심사 대상, 미리 확정) |

버튼 URL 은 **도메인은 고정, 뒷부분만 변수**로 신청한다. 도메인이 바뀌면 템플릿을 다시 승인받아야 한다.

---

## 1. 1차 메시지 (출고 후 첫 요청)

- 템플릿명: `시공사진 등록 안내 1차`
- 강조표기: 없음 / 메시지 유형: 기본형
- 버튼: 웹링크 · 버튼명 `시공사진 등록하기`
  - Mobile/PC URL: `https://photo.stonekim.co.kr/project/upload/#{토큰}`
- 승인 후 템플릿 코드 → `STONEKIM_TPL_FIRST`

**본문 (리워드 명시 버전)**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

구매하신 스톤킴 제품의 시공은 잘 마무리되셨나요?

완성된 공간의 사진을 보내주시면 확인 후 리워드를 드립니다.
· 사진 등록 확인 시 #{기본리워드}
· 스톤킴 시공사례로 선정 시 최대 #{최대리워드}

전문 촬영이 아니어도 괜찮습니다.
휴대폰으로 편하게 촬영해주세요.
```

**본문 (정보성 버전 — 위 문구가 반려될 경우)**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

구매하신 스톤킴 제품의 시공이 마무리되셨다면
완성된 현장 사진 등록을 부탁드립니다.

등록해주신 사진은 제품 품질 확인과 시공사례 검토에 사용되며,
검토 결과는 주문하신 연락처로 안내드립니다.

전문 촬영이 아니어도 괜찮습니다.
```

## 2. 2차 메시지 (1차 발송 7일 후, 미등록 고객)

- 템플릿명: `시공사진 등록 안내 2차`
- 버튼: 웹링크 · 버튼명 `사진 등록하고 리워드 신청하기` (정보성 버전은 `시공사진 등록하기`)
  - URL: `https://photo.stonekim.co.kr/project/upload/#{토큰}`
- 승인 후 템플릿 코드 → `STONEKIM_TPL_SECOND`

**본문 (리워드 명시 버전)**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

혹시 시공이 완료되셨다면 완성된 공간을 자랑해주세요.

· 사진 등록 확인 시 #{기본리워드}
· 스톤킴 시공사례로 선정 시 최대 #{최대리워드}

✓ 전문 촬영 필요 없음
✓ 휴대폰 사진 가능
✓ 등록 약 1분
```

**본문 (정보성 버전)**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

앞서 안내드린 시공사진 등록 관련 재안내드립니다.

시공이 완료된 현장의 사진을 등록해주시면
검토 후 결과를 안내드립니다.

✓ 휴대폰 사진 가능
✓ 등록 약 1분
```

· 스톤킴 시공사례로 선정 시 최대 #{최대리워드}

**본문 (정보성 버전)**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

시공사진 등록 마지막 안내드립니다.

```

## 4. 치환변수 목록 (시스템이 자동으로 넣는 값)

| 변수 | 들어가는 값 | 비고 |
|---|---|---|
| `#{고객명}` | 주문의 고객명 | 엑셀의 고객명 |
| `#{토큰}` | 주문별 고유 업로드 토큰 | 버튼 URL 뒷부분 |
| `#{기본리워드}` | 관리자 설정값 (기본 1만원) | 설정 화면에서 변경 |
| `#{최대리워드}` | 관리자 설정값 (기본 5만원) | 설정 화면에서 변경 |
| `#{링크}` | 전체 업로드 URL | 문자 대체발송 본문에 사용 |

## 5. 반려 위험과 대응

알림톡은 **정보성 메시지만** 허용한다. 구매 고객에게 보내는 사후 안내라 정보성으로 볼 여지가 있지만,
**금액·혜택을 강조하면 광고성으로 판단해 반려되는 사례가 많다.**

- 1순위: 리워드 명시 버전으로 신청 → 승인되면 등록률에 가장 유리
- 반려 시: 정보성 버전으로 재신청하고, 관리자 `설정 > 메시지 문구 유형`을 **정보성 문구**로 전환
  - 리워드 금액은 고객이 링크를 열면 업로드 페이지 첫 화면에서 그대로 보인다
- 정보성 버전도 반려되면: 채널 친구 대상 **친구톡(광고)** 또는 `(광고)` 표기 + 무료수신거부 번호를 넣은 **LMS** 로 전환
  - 이 경우 사전 광고 수신동의가 필요하므로 법무 확인 후 진행

## 6. 승인 후 할 일

```bash
STONEKIM_MSG_PROVIDER=solapi
STONEKIM_TPL_FIRST=승인받은_1차_템플릿코드
STONEKIM_TPL_SECOND=승인받은_2차_템플릿코드
STONEKIM_TPL_FINAL=승인받은_최종_템플릿코드
```

설정 후 반드시 아래로 점검한다.

```bash
node scripts/check-provider.js                       # 설정 누락 확인
node scripts/check-provider.js 010-XXXX-XXXX --send  # 관리자 번호로 실제 1건 발송
```
