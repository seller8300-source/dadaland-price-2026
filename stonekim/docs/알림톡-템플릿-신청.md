# 카카오 알림톡 템플릿 신청서 (스톤킴 시공사진 수집)

솔라피 콘솔 > 카카오 > 알림톡 템플릿에 그대로 입력할 내용이다.
검수는 영업일 기준 2~3일 걸리므로 **발송 시작 예정일 최소 1주 전에** 신청한다.

## 문구를 두 겹으로 나눈 이유

알림톡은 **정보성 메시지만** 허용한다. 금액·혜택을 강조하면 광고성으로 판단해 반려되는 사례가 많다.
그래서 아래와 같이 나눴다.

| 어디 | 무엇을 말하나 |
|---|---|
| **알림톡 본문** (심사 대상) | 리워드 금액 없이 "시공사진을 등록해 달라"는 안내만 |
| **업로드 페이지** (심사 대상 아님) | 버튼을 눌러 들어오면 첫 화면에 `사진 확인 후 최대 5만원의 시공사례 리워드` 안내 |

즉 **고객은 리워드를 보게 되지만, 심사에는 걸리지 않는 구조**다.
시스템 기본값도 정보성 문구(`설정 > 메시지 문구 유형 = 정보성 문구`)로 맞춰져 있다.

## 0. 사전 준비

| 항목 | 내용 |
|---|---|
| 카카오톡 채널 | 스톤킴 공식 채널 (비즈니스 인증 완료 필요) |
| 발신프로필 pfId | 솔라피에서 채널 연동 후 발급 → `STONEKIM_KAKAO_PFID` |
| 발신번호 | 사전 등록한 회사 번호 → `STONEKIM_MSG_SENDER` (문자 대체발송용) |
| 업로드 도메인 | 예: `https://photo.stonekim.co.kr` — **템플릿 신청 전에 확정** |

버튼 URL 은 **도메인 고정 + 뒷부분만 변수**로 신청한다. 도메인이 바뀌면 템플릿을 다시 승인받아야 한다.

---

## 1. 1차 메시지 (출고 후 첫 요청)

- 템플릿명: `시공사진 등록 안내 1차`
- 메시지 유형: 기본형 / 강조표기: 없음
- 버튼: 웹링크 · 버튼명 `시공사진 등록하기`
  - Mobile/PC URL: `https://photo.stonekim.co.kr/project/upload/#{토큰}`
- 승인 후 템플릿 코드 → `STONEKIM_TPL_FIRST`

**신청 본문 (정보성 — 이것으로 신청한다)**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

구매하신 스톤킴 제품의 시공이 마무리되셨다면
완성된 현장 사진 등록을 부탁드립니다.

등록해주신 사진은 제품 품질 확인과 시공사례 검토에 사용되며,
검토 결과는 주문하신 연락처로 안내드립니다.

전문 촬영이 아니어도 괜찮습니다.
```

**참고: 혜택 문구 버전** (심사에서 허용될 경우에만 사용. 관리자 설정에서 전환)

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

구매하신 스톤킴 제품의 시공은 잘 마무리되셨나요?

완성된 공간의 사진을 보내주시면 사진 확인 후 최대 #{최대리워드}의 시공사례 리워드를 드리고 있습니다.

전문 촬영이 아니어도 괜찮습니다.
휴대폰으로 편하게 촬영해주세요.
```

## 2. 2차 메시지 (1차 발송 7일 후, 미등록 고객)

- 템플릿명: `시공사진 등록 안내 2차`
- 버튼: 웹링크 · 버튼명 `시공사진 등록하기`
  - URL: `https://photo.stonekim.co.kr/project/upload/#{토큰}`
- 승인 후 템플릿 코드 → `STONEKIM_TPL_SECOND`

**신청 본문 (정보성)**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

앞서 안내드린 시공사진 등록 관련 재안내드립니다.

시공이 완료된 현장의 사진을 등록해주시면
검토 후 결과를 안내드립니다.

✓ 휴대폰 사진 가능
✓ 등록 약 1분
```

**참고: 혜택 문구 버전**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

혹시 시공이 완료되셨다면 완성된 공간을 자랑해주세요.

스톤킴 시공사례로 선정되는 현장에는 최대 #{최대리워드}의 리워드를 드립니다.

✓ 전문 촬영 필요 없음
✓ 휴대폰 사진 가능
✓ 등록 약 1분
```

## 3. 최종 메시지 (2차 발송 14일 후, 미등록 고객)

- 템플릿명: `시공사진 등록 안내 최종`
- 버튼: 웹링크 · 버튼명 `시공사진 등록하기`
  - URL: `https://photo.stonekim.co.kr/project/upload/#{토큰}`
- 승인 후 템플릿 코드 → `STONEKIM_TPL_FINAL`

**신청 본문 (정보성)**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

시공사진 등록 마지막 안내드립니다.

시공이 완료된 현장의 사진을 등록해주시면
검토 후 결과를 안내드리며, 이후에는 별도로 안내드리지 않습니다.
```

**참고: 혜택 문구 버전**

```
#{고객명}님, 안녕하세요. 스톤킴입니다.

스톤킴 시공사진 리워드 마지막 안내드립니다.

시공이 완료된 현장의 사진을 등록해주시면 확인 후 최대 #{최대리워드}의 리워드를 드립니다.

간단한 휴대폰 사진도 가능합니다.
```

## 4. 치환변수 (시스템이 자동으로 채운다)

| 변수 | 들어가는 값 |
|---|---|
| `#{고객명}` | 주문의 고객명 (엑셀에서 읽음) |
| `#{토큰}` | 주문별 고유 업로드 토큰 — 버튼 URL 뒷부분 |
| `#{최대리워드}` | 관리자 설정값 (기본 `5만원`) — 혜택 문구 버전에서만 사용 |
| `#{링크}` | 전체 업로드 URL — 문자 대체발송 본문에 사용 |

## 5. 반려되면

1. 반려 사유를 확인한다 (대부분 광고성 판단 또는 변수·버튼 형식 문제)
2. 정보성 본문에서 `✓` 목록처럼 홍보로 읽힐 수 있는 부분까지 덜어내고 재신청
3. 그래도 안 되면 채널 친구 대상 **친구톡(광고)** 또는 `(광고)` 표기 + 무료수신거부 번호를 넣은 **LMS**
   - 이 경우 사전 광고 수신동의가 필요하므로 법무 확인 후 진행

## 6. 승인 후

```
STONEKIM_MSG_PROVIDER = solapi
STONEKIM_TPL_FIRST    = 승인받은 1차 템플릿 코드
STONEKIM_TPL_SECOND   = 승인받은 2차 템플릿 코드
STONEKIM_TPL_FINAL    = 승인받은 최종 템플릿 코드
```

입력 후 반드시 대표님 번호로 먼저 확인한다.

```bash
node scripts/check-provider.js 010-XXXX-XXXX --send
```
