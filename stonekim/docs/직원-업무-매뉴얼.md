# 시공사진 수집 — 직원 업무 매뉴얼

관리자 화면 주소와 본인 아이디는 대표님께 받으세요.
첫 로그인 때 임시 비밀번호가 나오고, **비밀번호를 바꿔야 다른 화면으로 넘어갑니다.**

---

## 하루에 할 일은 두 가지뿐입니다

### 1. 사진 검수 (매일 · 5분)

`사진 검수` 메뉴에 **검토대기**가 쌓입니다.

- 사진을 열어보고 **시공 현장 사진이 맞는지** 봅니다.
- 맞으면 **승인**, 아니면 **반려** (사유를 적으면 고객에게 보입니다).
- 승인하면 리워드 결정 칸이 열립니다. **0원 / 1만원 / 3만원 / 5만원** 중 고릅니다.

> 금액 기준이 헷갈리면 대표님께 물어보세요. 임의로 정하지 마세요.

### 2. 리워드 지급 (주 1회)

`리워드` 메뉴 → **지급예정** 목록을 보고 실제로 송금한 뒤 **지급완료**로 바꿉니다.

---

## 주 1회 할 일

### 이카운트 주문 올리기

1. 이카운트 → **판매조회** → 기간 지정 → **엑셀 다운로드**
   - 열 구성은 건드리지 마세요. `일자-No. / 거래처명 / 연락처 / 품목명 / 금액합계` 그대로가 맞습니다.
2. 관리자 화면 → `엑셀 업로드` → 파일 선택 → **미리보기**
3. 미리보기에서 확인할 것:

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 🟢 정상 | 문제 없음 | 그대로 |
| 🟡 연락처에 번호가 2개 | 담당자 이름과 번호가 여러 개 | **첫 번째 번호로 나갑니다.** 시공사진 찍을 사람이 맞는지 확인 |
| 🟡 고객명이 전화번호 | 거래처명이 번호로 등록됨 | 카톡에 번호가 그대로 나옵니다. 이카운트에서 거래처명을 고치는 게 좋습니다 |
| 🔴 전화번호 오류 | 연락처가 없거나 번호가 아님 (쇼룸DP 등) | 등록 안 됩니다. 자사 건이면 정상입니다 |
| 🚫 취소 전표 | 금액이 마이너스 | 해당 주문의 발송을 자동으로 막습니다 |

4. **[N건 등록 · 자동발송 예약]** 클릭

> 같은 파일을 두 번 올려도 괜찮습니다. 이미 등록된 주문번호는 건너뜁니다.

---

## 발송은 사람이 누르지 않습니다

등록만 하면 시스템이 알아서 보냅니다.

```
주문 등록
   ↓  시공예정일 +2일  (없으면 출고일 +14일)
1차 알림톡 발송
   ↓  7일 뒤
2차 알림톡 발송          ← 사진이 등록되면 자동 취소됩니다
```

**2차를 누구에게 보낼지 직접 고르지 않습니다.** 1차를 받고도 사진을 안 올린 사람에게만 자동으로 나갑니다.

---

## 발송됐는지 확인하는 법

`발송 로그` 메뉴에서 봅니다.

| 상태 | 뜻 |
|---|---|
| **예약** | 아직 보낼 날짜가 안 됨 |
| **발송완료** | 카카오톡으로 도착 |
| **문자대체** | 카톡이 안 돼서 문자로 나감 (정상입니다) |
| **실패** | 못 나감 — 대표님께 알려주세요 |
| **사진등록 취소** | 사진을 올려서 후속 발송이 취소됨 (가장 좋은 상태입니다) |

`주문·현장` 메뉴에서 고객 한 명씩 눌러보면 그 사람의 발송 이력과 다음 예약일이 다 보입니다.

---

## 고객이 적는 항목 (2026-10 개편)

| 항목 | 필수 | 왜 받나 |
|---|---|---|
| 시공업체명 | ✅ | 우리 주문 내역과 맞춰보고, 어떤 제품이 들어갔는지 찾기 위해 |
| 업장명·상호 | | 카페·매장처럼 이름이 따로 있는 현장 |
| **상품권 받을 번호** | | **알림톡 받은 번호와 다를 수 있습니다.** 적혀 있으면 리워드 화면에 주황색으로 표시되니, 그 번호로 보내세요 |
| 업체명·업장명 노출 희망 | | 체크한 곳만 홍보할 때 이름을 같이 적습니다. 주문 상세에 `희망`/`미희망`으로 보입니다 |

## 하지 말아야 할 것

- **`설정` 메뉴는 직원 계정에 아예 안 보입니다.** 보인다면 관리자 권한으로 로그인된 것이니 대표님께 알려주세요.
- 고객이 전화로 "사진 어디에 올려요?" 하면, `주문·현장`에서 그 고객을 찾아 **업로드 주소**를 복사해서 문자로 보내주세요. 새로 만들지 마세요.
- 리워드 금액을 임의로 정하지 마세요.

---

## 자주 나오는 상황

**"고객이 링크가 안 열린다고 해요"**
→ `주문·현장`에서 그 고객의 업로드 주소를 복사해 다시 보내주세요. 오래된 카톡의 링크일 수 있습니다.

**"사진을 카톡으로 보내왔어요"**
→ `주문·현장` → 그 고객 → **사진 직접 등록**으로 올려주세요. 그러면 후속 발송도 같이 멈춥니다.

**"주문이 취소됐어요"**
→ 이카운트에 마이너스 전표가 잡히면 다음 업로드 때 자동으로 막힙니다. 급하면 `주문·현장` → 그 고객 → **자동 메시지 발송 제외**를 누르세요.

**"비밀번호를 잊었어요"**
→ 대표님께 말씀드리면 `계정 관리`에서 초기화해 줍니다.
