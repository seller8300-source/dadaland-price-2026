# 배포 가이드 — 고객 휴대폰에서 링크가 열리게 만들기

지금은 회사 PC 안(`localhost`)에서만 열린다. 고객 휴대폰에서 열리려면 **인터넷에 항상 켜져 있는 서버**가 필요하다.

## 무엇이 필요한가 (이 시스템의 조건)

| 조건 | 이유 |
|---|---|
| 24시간 켜져 있는 Node.js 서버 | 예약 발송 스케줄러가 1분마다 돈다 |
| **영구 디스크** | 고객 사진 원본과 DB(SQLite)가 파일로 저장된다 |
| HTTPS | 카카오톡에서 링크를 열 때 필수 |

> Vercel · Netlify · Cloudflare Pages 는 **쓸 수 없다.** 파일이 요청마다 사라지고(사진·DB 유실),
> 상시 실행 프로세스가 없어 예약 발송이 돌지 않는다.

## 권장: Render (웹에서 클릭만으로 가능)

GitHub 저장소를 연결하면 자동 배포되고, SSL·도메인 연결이 클릭 몇 번이다.

### 1단계 — 가입
1. https://render.com 접속 → **Get Started** → GitHub 계정으로 로그인
2. 저장소 접근 권한에서 `seller8300-source/dadaland-price-2026` 를 허용

### 2단계 — 서비스 만들기
대시보드 → **New +** → **Web Service** → 저장소 선택 후 아래와 같이 입력한다.

| 항목 | 값 |
|---|---|
| Name | `stonekim-photos` |
| Region | `Singapore` (한국에서 가장 가까움) |
| **Root Directory** | `stonekim` ← 반드시 입력 |
| Runtime | `Node` |
| Build Command | 비워 둔다 (설치할 패키지가 없음) |
| Start Command | `node server.js` |
| Instance Type | **Starter 이상 (유료)** |

> Free 플랜은 **디스크를 붙일 수 없고 15분 후 잠들기** 때문에 사진과 예약 발송이 날아간다. 반드시 유료 플랜.

### 3단계 — 디스크 연결 (가장 중요)
서비스 생성 화면 하단 **Advanced** → **Add Disk**

| 항목 | 값 |
|---|---|
| Name | `stonekim-data` |
| Mount Path | `/data` |
| Size | `5 GB` (사진 약 2~3만 장 분량, 나중에 늘릴 수 있음) |

디스크를 안 붙이면 **재배포할 때마다 고객 사진과 주문 데이터가 전부 사라진다.**

### 4단계 — 환경변수
**Environment** 탭에서 입력한다.

```
STONEKIM_DATA_DIR      = /data
STONEKIM_SECURE_COOKIE = 1
STONEKIM_ADMIN_USER    = admin
STONEKIM_ADMIN_PASSWORD= (직접 정한 16자 이상 비밀번호)
STONEKIM_MSG_PROVIDER  = mock          ← 알림톡 승인 전까지는 mock 유지
STONEKIM_BASE_URL      = (5단계에서 입력)
```

### 5단계 — 주소 확정
배포가 끝나면 `https://stonekim-photos.onrender.com` 같은 주소가 나온다.
이 주소를 `STONEKIM_BASE_URL` 에 넣고 **Save → 재배포**한다.
이 값이 틀리면 고객에게 나가는 링크가 깨지므로 반드시 확인한다.

### 6단계 — 접속 확인
- `https<주소>/health` → `{"ok":true...}` 가 보이면 정상
- `https<주소>/admin` → 관리자 로그인 화면
- 비밀번호를 지정하지 않았다면 Render **Logs** 탭에 임시 비밀번호가 출력된다

### 7단계 — 회사 도메인 연결 (선택, 권장)
**Settings → Custom Domains → Add** 에서 `photo.stonekim.co.kr` 입력 →
도메인 관리업체(가비아·후이즈 등)에서 안내된 CNAME 을 등록하면 SSL 은 자동 발급된다.
연결 후 `STONEKIM_BASE_URL` 을 새 주소로 바꾸고 재배포한다.

> 알림톡 템플릿의 버튼 URL 에 도메인이 들어가므로, **템플릿 신청 전에 도메인을 확정**하는 편이 좋다.
> 나중에 바꾸면 템플릿을 다시 승인받아야 한다.

### 비용 (2026년 9월 기준, 가입 시 실제 금액 확인)
- Starter 인스턴스 약 $7/월
- 디스크 5GB 약 $1.25/월
- 합계 월 1만 2천원 안팎

## 대안 1 — 국내 VPS + Docker

카페24 / 가비아 / NHN Cloud / 네이버 클라우드 등 국내 서버를 쓰면 응답이 더 빠르고 결제가 편하다.

```bash
docker build -t stonekim .
docker run -d --name stonekim --restart always \
  -p 3000:3000 \
  -v /srv/stonekim-data:/data \
  -e STONEKIM_BASE_URL=https://photo.stonekim.co.kr \
  -e STONEKIM_SECURE_COOKIE=1 \
  -e STONEKIM_ADMIN_PASSWORD='직접-정한-비밀번호' \
  stonekim
```

이 경우 앞단에 Nginx(또는 Caddy)로 HTTPS 를 직접 붙여야 한다. 관리할 게 늘어나므로
서버 담당자가 없다면 Render 를 권한다.

## 대안 2 — Fly.io
CLI 로 다루는 데 익숙하면 `fly launch` + `fly volumes create stonekim_data --size 5` 로 비슷하게 구성할 수 있다.

## 배포 후 반드시 할 것

- [ ] `설정 > 발송 허용 번호` 에 **대표님 번호만** 넣어 둔다 (고객 오발송 차단)
- [ ] 관리자 비밀번호 변경
- [ ] 휴대폰에서 `https<주소>/admin` 로그인 확인
- [ ] 백업: Render 는 디스크 스냅샷 기능을 제공한다. 최소 주 1회, 사진이 쌓이면 별도 보관 고려
- [ ] 저장소가 공개(public)이므로 **환경변수(비밀번호·API 키)는 절대 코드에 넣지 않는다**
