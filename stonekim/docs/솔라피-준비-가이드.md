# 카카오 알림톡 실발송 준비 — 순서대로 따라 하기

처음 하는 경우 **전체 2~3주** 걸린다고 보면 된다. 가장 오래 걸리는 건 ③ 비즈니스 인증과 ⑥ 템플릿 심사다.
(사이트 메뉴 이름은 개편에 따라 조금씩 달라질 수 있다. 큰 흐름은 동일하다.)

---

## ① 카카오톡 채널 만들기 — 반나절

1. https://center-pf.kakao.com 접속 → 카카오 계정으로 로그인
2. **새 채널 만들기** → 채널명(예: `스톤킴`), 검색용 아이디(예: `@stonekim`) 입력
3. 이미 회사 채널이 있으면 그대로 사용한다

## ② 카카오 비즈니스 채널(비즈니스 인증) — 1~3일

1. https://business.kakao.com 접속 → 위에서 만든 채널 선택
2. **비즈니스 채널 전환** 신청 → 사업자등록증 업로드
3. 승인되어야 알림톡을 보낼 수 있다. **여기서 막히면 이후 단계 전부 진행 불가**

## ③ 솔라피 가입 — 10분

1. https://solapi.com 접속 → **회원가입** (사업자 정보로 가입)
2. 로그인 후 **잔액 충전** — 처음엔 1~2만원이면 충분
   - 알림톡 1건 10원 내외, 문자(LMS) 30~40원 내외 (현재 단가는 콘솔에서 확인)

## ④ 발신프로필 등록 (솔라피 ↔ 카카오 채널 연결) — 30분

1. 솔라피 콘솔 → **카카오** 메뉴 → **채널(발신프로필) 추가**
2. 채널 검색용 아이디(`@stonekim`)와 채널 관리자 휴대폰번호 입력
3. 카카오톡으로 오는 **인증번호(토큰)** 를 입력하면 연결 완료
4. 연결 후 표시되는 **pfId**(`KA01PF...` 로 시작) 를 메모 → `STONEKIM_KAKAO_PFID`

## ⑤ 발신번호 등록 (문자 대체발송용) — 1~2일

알림톡이 실패하면 문자로 대신 보내는데, 이때 쓸 회사 번호를 미리 등록해야 한다.

1. 솔라피 콘솔 → **발신번호 관리** → 등록
2. 통신서비스 이용증명원(통신사에서 발급) 또는 지정된 서류 업로드
3. 승인된 번호를 `STONEKIM_MSG_SENDER` 에 입력 (예: `0322000000`)

## ⑥ 알림톡 템플릿 등록 및 심사 — 영업일 2~3일 (반려되면 더)

1. 솔라피 콘솔 → **카카오 > 알림톡 템플릿** → 새 템플릿
2. [docs/알림톡-템플릿-신청.md](알림톡-템플릿-신청.md) 의 **정보성 버전 본문을 그대로** 붙여넣는다
   - 3개(1차 / 2차 / 최종)를 각각 등록
   - 버튼: `웹링크` · 버튼명 `시공사진 등록하기`
   - 버튼 URL: `https://photo.stonekim.co.kr/project/upload/#{토큰}` ← **배포 주소 확정 후 입력**
3. 심사 통과 후 나오는 템플릿 코드(`KA01TP...`)를 메모
   → `STONEKIM_TPL_FIRST` / `STONEKIM_TPL_SECOND` / `STONEKIM_TPL_FINAL`

> **중요**: 본문에 리워드 금액을 쓰면 광고성으로 반려될 수 있어, 기본 문구는 금액이 없는 정보성 버전이다.
> 리워드 안내는 고객이 버튼을 눌러 들어온 **업로드 페이지에서** 크게 보여준다.
> 혹시 혜택 문구로 승인이 난다면 관리자 `설정 > 메시지 문구 유형`을 `리워드 기준 명시`로 바꾸면 된다.

## ⑦ API 키 발급 — 5분

1. 솔라피 콘솔 → **개발/연동 > API Key 관리** → 새 API Key 생성
2. **API Key** 와 **API Secret** 이 나온다. Secret 은 생성 시 한 번만 보이므로 반드시 복사해 둔다
   → `STONEKIM_SOLAPI_API_KEY`, `STONEKIM_SOLAPI_API_SECRET`

## ⑧ 서버에 입력 — 10분

Render 대시보드 → 서비스 → **Environment** 에서 아래를 입력하고 저장(재배포)한다.

```
STONEKIM_MSG_PROVIDER      = solapi
STONEKIM_SOLAPI_API_KEY    = (⑦에서 받은 값)
STONEKIM_SOLAPI_API_SECRET = (⑦에서 받은 값)
STONEKIM_KAKAO_PFID        = KA01PF...      (④)
STONEKIM_MSG_SENDER        = 0322000000     (⑤)
STONEKIM_TPL_FIRST         = KA01TP...      (⑥)
STONEKIM_TPL_SECOND        = KA01TP...
STONEKIM_TPL_FINAL         = KA01TP...
```

## ⑨ 점검

관리자 `설정` 화면 맨 위에 **발송 채널**이 표시된다.
빠진 값이 있으면 "설정 누락: …" 으로 어떤 값이 없는지 알려준다.

서버에 직접 접속할 수 있다면 아래 명령으로도 점검할 수 있다.

```bash
node scripts/check-provider.js                       # 설정 점검 + 실제 나갈 문구 확인
node scripts/check-provider.js 010-XXXX-XXXX --send  # 대표님 번호로 1건 실제 발송
```

## ⑩ 대표님 번호로 전체 흐름 테스트

[docs/운영-런북.md](운영-런북.md) 의 **STEP 3** 를 그대로 따라 한다.
`발송 허용 번호`에 대표님 번호만 들어 있는 동안에는 **고객에게 한 건도 나가지 않는다.**

## 자주 막히는 지점

| 증상 | 원인 / 해결 |
|---|---|
| 템플릿 심사 반려 | 혜택·금액 표현 → 정보성 버전으로 재신청 |
| 알림톡은 실패하고 문자만 감 | 템플릿 코드 오입력, pfId 불일치, 변수명 불일치 |
| 문자도 실패 | 발신번호 미승인 또는 잔액 부족 |
| 링크를 눌러도 안 열림 | `STONEKIM_BASE_URL` 이 실제 주소와 다름 |
| 버튼 URL 이 템플릿과 다르다고 반려 | 버튼 URL 의 도메인은 고정, 뒷부분만 `#{토큰}` 변수여야 함 |
