# STONEKIM 시공사진 자동수집 시스템 (MVP)

자재 출고 이후 고객에게 시공사진을 요청하는 업무를 자동화한다.

```
출고 엑셀 업로드 → 자동 메시지 발송 → 미등록 시 자동 재발송
   → 고객 사진 업로드 → 자동발송 즉시 중단 → 관리자 검수 → 리워드 관리
```

1차 버전의 최우선 KPI는 **시공사진 등록률**이다. 기능의 많고 적음보다 실제 사진이 회수되는지를 먼저 검증한다.

## 빠른 실행

```bash
cd stonekim
node server.js            # http://localhost:3000/admin
node scripts/seed.js      # (선택) 데모 주문 5건 생성
npm test                  # 47개 테스트
```

Node.js 22.5 이상이면 **추가 설치 없이** 동작한다. (`node:sqlite`, `node:http` 등 내장 모듈만 사용)
최초 실행 시 관리자 계정이 없으면 임시 비밀번호가 콘솔에 출력된다. 로그인 후 설정 화면에서 변경한다.

환경변수는 `.env.example` 참고. 운영 시 최소한 `STONEKIM_BASE_URL`(고객 링크 주소)과
`STONEKIM_ADMIN_PASSWORD`, 발송 게이트웨이 설정은 지정해야 한다.

## 발송 규칙

| 조건 | 1차 | 2차 | 최종 |
|---|---|---|---|
| 시공예정일 있음 | 시공예정일 +2일 | 1차 발송 +7일 | 2차 발송 +14일 |
| 시공예정일 없음 | 출고일 +14일 | 1차 발송 +7일 | 2차 발송 +14일 |

- 발송 시각은 KST 기준 설정값(기본 10시)이며 `설정` 화면에서 바꿀 수 있다.
- **고객이 사진을 등록하는 즉시 해당 주문의 모든 예약 메시지가 취소된다.** (`CANCELED_PHOTO`)
- 발송 직전에도 사진 등록·발송 제외 여부를 다시 확인하므로, 이미 등록한 고객에게는 발송되지 않는다.
- 최종 메시지 발송 이후에는 자동 요청이 종료된다.
- 알림톡 실패 시 SMS/LMS(90바이트 초과 시 LMS)로 자동 대체발송하고 결과를 모두 기록한다.

## 화면

| 구분 | 경로 | 내용 |
|---|---|---|
| 고객 | `/project/upload/{token}` | 모바일 우선 사진 등록 (로그인 없음, 1분 이내 완료) |
| 고객 | `/project/upload/{token}/done` | 등록 완료 안내 |
| 관리자 | `/admin` | 금월 현황 + MVP 성공 기준 지표 |
| 관리자 | `/admin/projects` | 주문·현장 목록 (필터 8종 / 고객명·전화·주문번호·현장·제품 검색) |
| 관리자 | `/admin/projects/:id` | 현장 상세 · 사진 검수 · 리워드 · 발송 이력 · 수동 제어 |
| 관리자 | `/admin/review` | 검수 대기 현장 모아보기 |
| 관리자 | `/admin/rewards` | 리워드 상태 관리 |
| 관리자 | `/admin/messages` | 발송 로그 (성공/실패/대체발송/취소) |
| 관리자 | `/admin/import` | 출고 엑셀 업로드 → 미리보기 → 등록 |
| 관리자 | `/admin/settings` | 문구 관리 · 테스트 발송 · 비밀번호 · 작업 로그 |

## 출고 엑셀 업로드

- `.xlsx` 와 `.csv/.tsv` 를 지원한다. (xlsx 파서는 외부 라이브러리 없이 구현)
- 헤더 표기가 달라도 매핑된다. 예: `주문번호/주문 No/수주번호`, `휴대폰번호/연락처/핸드폰`, `시공예정일/시공일/설치예정일`.
- 등록 전 미리보기에서 **총 건수 / 정상 / 전화번호 오류 / 중복 주문**을 확인한다. 정상 건만 등록된다.
- 엑셀에서 앞자리 0 이 사라진 번호(`1012345678`)와 엑셀 날짜 시리얼 값은 자동 보정한다.
- 시공예정일은 비워둘 수 있다(NULL 허용). 중복 주문번호는 새 주문·고객을 만들지 않는다.
- **대량발송 실수 방지**: 등록 시 예약시각이 이미 지난 건은 즉시 발송되지 않고 다음 발송창으로 미뤄진다.
  발송을 전혀 걸지 않으려면 `등록 · 발송 보류` 로 등록한 뒤 현장별로 수동 발송한다.

## 고객 업로드 화면

- 모바일 우선, 카카오톡 인앱브라우저 기준으로 구성했다. 회원가입·로그인 없음.
- 사진 최소 3장 / 최대 10장, 사진첩에서 여러 번 나눠 선택해도 누적된다.
- 업로드 전 브라우저에서 최대 1920px·JPEG 로 재인코딩해 용량을 줄인다.
  iOS 의 HEIC 는 이 과정에서 JPEG 로 변환된다. 변환이 불가한 환경에서는 원본을 그대로 전송하고
  서버가 HEIC 로 저장하면서 `needs_convert` 로 표시한다(관리자 화면에 `HEIC` 배지).
- 자바스크립트가 막힌 환경에서는 일반 폼 전송으로도 등록된다(압축만 생략).
- 사진 활용 동의는 필수이며, 동의 시각과 **그 시점의 동의 문구를 스냅샷으로 보관**한다.
  동의·개인정보 문구는 관리자 설정 화면에서 수정할 수 있다.

## 데이터 구조

`CUSTOMER` / `PROJECT(ORDER)` / `MESSAGE` / `PHOTO` / `REWARD` 를 분리했고,
운영에 필요한 `IMPORT_BATCH`(업로드 미리보기), `PAGE_VISIT`(방문률), `AUDIT_LOG`(관리자 작업),
`ADMIN_USER/SESSION`, `SETTINGS` 를 추가했다. 스키마는 `src/db.js` 참고.

주요 상태값

- `projects.status`: `READY` · `SENT_1` · `SENT_2` · `SENT_FINAL` · `PHOTO_SUBMITTED`
- `messages.status`: `SCHEDULED`(예약) · `SENT`(발송완료) · `FAILED`(발송실패) · `SENT_SMS`(SMS 대체발송)
  · `CANCELED_PHOTO`(사진등록으로 취소) · `CANCELED_ADMIN`(관리자 중단)
- `photos.review_status`: `PENDING` · `USABLE`(사용가능) · `UNUSABLE`(사용불가), `is_best`(★ BEST)
- `rewards.status`: `PENDING`(검토대기) · `SCHEDULED`(지급예정) · `PAID`(지급완료) · `EXCLUDED`(지급제외)

## 보안

- 업로드 링크는 256bit 난수 토큰(`/project/upload/{token}`)이며 전화번호·주문번호를 노출하지 않는다.
- 관리자 페이지는 세션 인증(HttpOnly·SameSite 쿠키, scrypt 비밀번호 해시)과 CSRF 토큰으로 보호한다.
- 사진 파일은 관리자 인증을 거친 `/admin/media/:id` 로만 제공된다. 파일명은 서버가 생성하고 경로 탈출을 차단한다.
- 업로드 파일은 확장자가 아닌 **매직바이트**로 형식을 검증하고(JPG/PNG/WebP/HEIC), 용량·장수를 제한한다.
- 관리자 주요 작업(로그인 실패, 발송, 제외, 검수, 리워드, 업로드, 설정 변경)은 감사 로그에 남는다.
- 목록·로그 화면의 전화번호는 마스킹해서 표시한다.

## 발송 게이트웨이 연동

기본값은 `mock`(실제 발송 없이 성공 처리)이라 개발·시연 중 고객에게 메시지가 나가지 않는다.
실제 발송은 `STONEKIM_MSG_PROVIDER=http` 로 전환하고 엔드포인트/키를 설정한다.
사업자(솔라피·NHN 등)별 요청 형식은 `src/messaging.js` 한 파일만 수정하면 된다.
운영 전환 전 반드시 `설정 → 테스트 발송`으로 관리자 번호에 문구와 링크를 확인한다.

## MVP 범위 밖 (2차 개발)

AI 사진 검수/보정, 콘텐츠 자동 생성(블로그·인스타·PROJECT 페이지), ERP 실시간 연동,
자동 계좌송금, 복잡한 CRM 은 포함하지 않는다. 리워드는 지급 여부만 관리한다.

## 구조

```
server.js              HTTP 서버 · 라우팅 · 스케줄러 기동
scripts/seed.js        데모 데이터
src/db.js              스키마 · 설정값 · 감사 로그
src/scheduler.js       발송 예약/취소/전송 규칙 (핵심 로직)
src/messaging.js       알림톡 → SMS/LMS 대체발송 어댑터
src/templates.js       1차/2차/최종 메시지 본문
src/import.js          엑셀 검증 · 미리보기 · 등록
src/xlsx.js            의존성 없는 xlsx/CSV 파서
src/photos.js          이미지 검증·저장·검수
src/auth.js            관리자 인증 · 세션 · CSRF
src/routes/            고객 / 관리자 라우트
src/views/             고객 / 관리자 화면
test/                  47개 테스트 (발송 규칙·업로드·권한·엑셀)
```
