# 케이오마케팅 데이터 요청서

## 1. 2025년 1~8월 원본 RAW REPORT 재발행 요청 (가장 급함)

API 데이터 보존기간은 리포트 종류마다 다르고, 2025년 1~8월 데이터가 API 로 **영구 복원
가능하다고 가정하지 않습니다**. 현재 Excel 이 장기 Benchmark 의 중요한 Source 이므로
원본 재발행을 요청합니다. 수령 즉시 별도 Archive 로 보관합니다.

> 안녕하세요, 다다랜드입니다.
> 2025년 1월 ~ 8월 10개 계정(다다그룹, 타임렌탈, OMBC, MBC렌탈, 마니, 으라차차, 다있지,
> 킴샵, 빌리마켓, 현대도크)의 **가공 전 원본 리포트(RAW)** 재발행을 요청드립니다.
> 가공 PDF/Excel 이 아니라 네이버 검색광고에서 내려받은 원본 Export 파일 그대로
> (계정별 개별 파일, 일자별 행) 부탁드립니다.

## 2. 앞으로 매월 받을 RAW 필드

가공본이 아니라 원본 Export 를 그대로 받습니다. 컬럼명은 원본 그대로 두셔도 됩니다.

| 필드 | 설명 |
|---|---|
| `date` | 통계 일자 (일 단위) |
| `account` | 계정 |
| `campaign` | 캠페인명 |
| `adgroup` | 광고그룹명 |
| `keyword` | 등록 키워드 |
| `keyword_id` | 키워드 ID (nccKeywordId) |
| `impression` | 노출수 |
| `click` | 클릭수 |
| `CTR` | 클릭률 |
| `CPC` | 평균 클릭비용 |
| `cost` | 총비용 |
| `average_rank` | 평균노출순위 |
| `device` | PC / MOBILE |
| `creative` | 소재(제목/설명/URL) |
| `landing_url` | 연결 URL |
| `search_term` | 실제 검색어 |
| `conversion` | 전환수 |

## 3. 현재 확인된 데이터 문제 (수정 요청 항목)

아래는 시스템이 자동으로 탐지한 문제입니다. 원본 재발행 시 함께 확인 부탁드립니다.

1. **전환수 시트** — 여러 계정에 동일한 데이터가 복사되어 있습니다. 계정별 실제 값 필요.
2. **쇼핑검색 상세** — 여러 계정에 동일 데이터가 복사된 정황이 있습니다.
3. **키워드 상세** — 평균순위/품질지수/전환 영역에 템플릿 문자열이 남아 있습니다.
4. **으라차차 키워드 비용** — MBC렌탈과 동일한 일별 비용값이 반복 확인됩니다.
5. **캠페인 라벨** — 키워드가 실제 상품과 다른 캠페인으로 분류된 사례가 있습니다
   (예: 행사 키워드가 물류 캠페인에 포함). 캠페인 라벨은 참고만 하고 있으나,
   원본에서 정정 가능하면 정정 부탁드립니다.

## 4. 실행 요청 형식

CEO 승인 후 아래 형식으로 전달합니다. 시스템이 광고를 직접 변경하지 않습니다.

```
안녕하세요, 다다랜드입니다.
2026-08-31 기준 데이터 확인 결과 아래 항목 진행 요청드립니다.

1. [현대도크] '난방기렌탈' (난방) 광고 중단 — 해당 계정은 허용 상품군 외 집행 금지.
2. [마니] CPC 급등 키워드 상위 20개 목록과 현재 입찰가/평균순위 회신 요청.
3. [신규] '킨텍스 행사집기렌탈' 등록 검토 요청 — 근거: 실제 검색어로 9일 반복 유입 …

각 항목 처리 후 변경 전/후 수치(노출, 클릭, CPC, 평균순위, 비용)를 함께 회신 부탁드립니다.
```

이 메시지는 `POST /api/v1/reports/daily/agency-message` 가 자동 작성합니다
(예: `{"approved_by": "CEO", "selected": [1, 3, 5]}`).
