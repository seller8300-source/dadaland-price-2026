# 분석 해석 가이드

## AI 가 항상 먼저 던지는 질문 (§39)

1. 매출이 늘었는가?
2. 광고비는 얼마나 늘었는가?
3. 광고비보다 매출이 더 빨리 늘었는가?
4. 광고비가 늘었다면 클릭 때문인가 CPC 때문인가?
5. 어느 상품군에서 증가했는가?
6. 어느 키워드가 원인인가?
7. 시장 자체가 커진 것인가?
8. 불필요한 상위입찰인가?
9. 더 싸고 정확한 검색어가 존재하는가?
10. 현재 놓치고 있는 수요는 없는가?

4~7번은 `GET /api/v1/benchmark/spend-driver` 가 자동으로 답합니다.

## 광고비 증가 원인 분해

```
Δcost = (Δclicks × CPC_before) + (ΔCPC × clicks_before) + (Δclicks × ΔCPC)
```

- 한 요인이 변화량의 65% 이상 → 단일 원인 (`A_CLICK_GROWTH` / `B_CPC_RISE`)
- 그 외 → `C_CLICK_AND_CPC`
- 보조 원인: 평균순위 상승(`D`), 캠페인 확대(`F`), 신규키워드(`G`), 비효율 유입(`H`)
- 검색시장 확대(`E`) 는 외부 검색량 데이터가 붙기 전까지 단정하지 않습니다.

## 계정별 플래그의 의미

플래그는 **판정이 아니라 확인 순서**입니다.

| 플래그 | 무엇을 확인할 것인가 |
|---|---|
| `EFFICIENCY_WARNING` | 고CPC 키워드, 과도한 상위노출 |
| `CPC_UP_CTR_DOWN` | 평균순위·랜딩·소재·실제 검색어 |
| `EXPANSION_TYPE` / `CLICK_EXPANSION` | 입찰이 아니라 유입 품질·검색어·전환 |
| `LOW_CPC_ACCOUNT` | 저비용 고의도 키워드 발굴 사례로 활용 (삭감 대상 아님) |
| `VOLUME_LEADER_SLOW_GROWTH` | 규모가 크다 ≠ 효율이 좋다 |
| `EFFICIENCY_BENCHMARK_CANDIDATE` | **후보**일 뿐, 전환 데이터 전에는 확정하지 않음 |
| `TOP_RANK_FIXED_WARNING` | 1위 고정 시 전환 차이 비교 (1.2위 vs 3.1위) |
| `GROWTH_ACCOUNT` | 광고비 증가율이 아니라 매출/기여이익 증가율로 평가 |
| `DATA_QUALITY_BLOCKED` | 데이터 오류 확인 — API 연결 전 상세 판단 보류 |
| `POLICY_VIOLATION` | 허용 상품군 외 광고 — 즉시 확인 |

## 경쟁 비용 두 가지

- **Allowed Competition Spend** — 시장이 크거나 시즌이라 의도적으로 여러 팀이 운영하는 비용
- **Reallocation Review Spend** — 시장규모 대비 계정 수가 과도하거나 효율이 낮은 계정의 비용

검토 대상은 **삭감 확정이 아닙니다**. 예: 냉방 성수기에 5개 팀이 같은 키워드를 운영하는 것은
허용, 비시즌 침구를 5개 팀이 운영하는 것은 경고 (이불 Primary 는 OMBC).

## 매출 생산성 판정

| 상황 | 판정 |
|---|---|
| 광고비 +20% / 매출 +45% | `PRODUCTIVITY_IMPROVED` |
| 광고비 +70% / 매출 +20% | `REVENUE_UP_PRODUCTIVITY_DOWN` |
| 광고비 +300% / 매출 +5% | `INVESTIGATE_NOW` |
| 매출 데이터 없음 | `DATA_INSUFFICIENT` (광고비만으로 효율 판정 금지) |

## 광고비 대비 필요한 매출

```
절대 손익분기 매출 = 광고비 / 기여마진율
```

기여마진율 30% 기준 광고비 1억 → 3.33억. 실무 목표는 광고비율 시나리오로 따로 봅니다
(20% → 5억, 15% → 6.67억, 10% → 10억). 팀별/상품별 마진을 입력하면 자동 재계산됩니다
(`GET /api/v1/productivity/breakeven`).

## 하지 않는 판단 (§11)

데이터 없이 다음을 단정하지 않습니다.

- 광고비 많음 = 나쁜 광고
- CPC 낮음 = 좋은 광고 / CTR 높음 = 매출 좋은 광고
- 메인키워드 = 나쁜 광고 (메인어는 자동 OFF 하지 않습니다)
- 렌탈/임대/대여 포함 = 무조건 좋은 광고
- 동일키워드 여러 팀 = 무조건 낭비
- 검색량 적음 = 삭제 (지역/행사/용도 고의도 키워드는 낮은 입찰로 유지)
